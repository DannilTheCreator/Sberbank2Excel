# 🚀 Quick Start Guide - Многопечений PDF в Excel

## Самый быстрый способ

```bash
# 1. Поместите все PDF в одну папку
mkdir my_bank_statements
# Скопируйте все PDF файлы сюда

# 2. Обработайте их одной командой
python3 multi_pdf_to_excel.py -d my_bank_statements -o results.xlsx

# 3. Готово! Откройте results.xlsx в Excel
```

## Три варианта использования

### Вариант 1: Все PDF в один лист

```bash
python3 multi_pdf_to_excel.py -o combined.xlsx
```
**Результат:** Excel файл со всеми операциями в одном листе
**Файлы из которых:** Сохраняется в колонке "Файл"

### Вариант 2: Каждый PDF в отдельный лист

```bash
python3 multi_pdf_to_excel.py -s -o combined.xlsx
```
**Результат:** Excel файл с отдельными листами для каждого PDF
**Листы:** statement_1, statement_2, statement_3 и т.д.

### Вариант 3: Из конкретной папки

```bash
python3 multi_pdf_to_excel.py -d /path/to/pdfs -o output.xlsx
```
**Результат:** Обрабатывает все PDF из указанной папки

## Параметры

| Опция | Описание |
|-------|---------|
| `-o FILE` | Название выходного Excel файла |
| `-d DIR` | Папка с PDF файлами |
| `-s` | Каждый PDF в отдельном листе |
| `--help` | Показать полную справку |

## Примеры для разных случаев

**📁 Обработать все PDF из текущей папки:**
```bash
python3 multi_pdf_to_excel.py -o all.xlsx
```

**📂 Обработать PDF из другой папки:**
```bash
python3 multi_pdf_to_excel.py -d ~/Documents/statements -o result.xlsx
```

**📄 Обработать конкретные файлы:**
```bash
python3 multi_pdf_to_excel.py jan.pdf feb.pdf mar.pdf -o q1.xlsx
```

**📋 Разные листы для каждого файла:**
```bash
python3 multi_pdf_to_excel.py -s -d ./statements -o archive.xlsx
```

**🔄 Сочетание параметров:**
```bash
python3 multi_pdf_to_excel.py -s -d ./my_pdfs -o result.xlsx
```
Обрабатывает PDF из `./my_pdfs`, сохраняет в разные листы

## Часто задаваемые вопросы

**Q: Где скачать PDF?**
A: Скачайте выписки из интернет-банка Сбербанка или T-Bank

**Q: Сколько PDF можно обработать?**
A: Теоретически неограниченно. Практически - столько сколько памяти. На обычном ПК легко обрабатывается 100+ файлов.

**Q: Как быстро это работает?**
A: Примерно 1 PDF в секунду. 100 файлов - минута работы.

**Q: Можно ли обработать один PDF?**
A: Да! `python3 multi_pdf_to_excel.py single.pdf -o result.xlsx`

**Q: Что если PDF не распознался?**
A: Скрипт покажет ошибку и продолжит обработку остальных

**Q: Можно ли отправить файл другому человеку?**
A: Да! Excel файл можно открыть в любой программе, передать по email и т.д.

## Трубка

Если нужно использовать результат в другой программе:

```python
import pandas as pd

# Загрузить данные
df = pd.read_excel('combined.xlsx')

# Показать первые 5 операций
print(df.head())

# Итого по файлам
print(df.groupby('Файл')['Сумма в валюте счёта'].sum())

# Экспорт в CSV
df.to_csv('data.csv', index=False)
```

## ⚡ Автоматизация

Добавьте в автозагрузку или cron для регулярной обработки:

```bash
# Каждый месяц обрабатывать PDF
0 1 1 * * cd ~/statements && python3 ~/multi_pdf_to_excel.py -o monthly_$(date +%Y%m).xlsx
```
