# 📊 Конвертация нескольких PDF в Excel

Скрипт для загрузки нескольких PDF выписок банка и объединения их в один Excel файл.

## ✨ Возможности

- 📄 Загрузка одного или нескольких PDF файлов
- 📁 Автоматический поиск всех PDF в папке
- 📝 Объединение в один лист или разные листы
- 🔄 Автоматическая сортировка по дате
- ⚡ Быстрая обработка (параллельно для разных файлов)
- 📊 Сохранение информации об источнике файла

## 🚀 Быстрый старт

### Python скрипт

```bash
# Все PDF из текущей папки в один Excel
python3 multi_pdf_to_excel.py -o combined.xlsx

# Все PDF в разные листы
python3 multi_pdf_to_excel.py -s -o combined.xlsx

# Конкретные PDF файлы
python3 multi_pdf_to_excel.py file1.pdf file2.pdf file3.pdf -o combined.xlsx

# PDF из конкретной папки
python3 multi_pdf_to_excel.py -d ./my_pdfs -o combined.xlsx
```

### Shell скрипт (Linux/Mac)

```bash
# Сделать скрипт исполняемым
chmod +x run_multi_pdf.sh

# Использование
./run_multi_pdf.sh combined.xlsx
./run_multi_pdf.sh -s combined.xlsx
./run_multi_pdf.sh -d ./pdfs combined.xlsx
```

## 📋 Примеры

### Пример 1: Объединение всех PDF в текущей папке

```bash
cd /path/to/pdfs
python3 ../multi_pdf_to_excel.py -o all_statements.xlsx
```

Результат: `all_statements.xlsx` с 404 операциями из 4 PDF файлов

### Пример 2: Каждый PDF в отдельном листе

```bash
python3 multi_pdf_to_excel.py -s -o statements.xlsx
```

Результат: `statements.xlsx` с листами:
- `8542637896` (101 операция)
- `test_pdf_1` (101 операция)
- `test_pdf_2` (101 операция)
- `test_pdf_3` (101 операция)

### Пример 3: Конкретные файлы

```bash
python3 multi_pdf_to_excel.py jan.pdf feb.pdf mar.pdf -o q1_2026.xlsx
```

### Пример 4: Из другой папки

```bash
python3 multi_pdf_to_excel.py -d /home/user/bank_statements -o combined.xlsx
```

## 🔧 Опции командной строки

```
-h, --help              Показать справку
-o, --output FILE       Имя выходного файла (по умолчанию: combined.xlsx)
-d, --directory DIR     Папка с PDF файлами
-s, --separate          Каждый PDF в отдельном листе (по умолчанию: один лист)
--temp-dir DIR          Папка для временных файлов
```

## 📊 Структура результирующего Excel файла

### Режим 1: Все в одном листе (по умолчанию)

| Файл | Дата операции | Дата обработки | Описание операции | ... |
|------|---------------|---|---|---|
| 8542637896.pdf | 25.04.26 | 25.04.26 | Пополнение. Сбербанк Онлайн | ... |
| 8542637896.pdf | 25.04.26 | 25.04.26 | Плата за обслуживание | ... |
| test_pdf_1.pdf | 25.04.26 | 25.04.26 | Пополнение. Сбербанк Онлайн | ... |

**Преимущества:**
- Легко фильтровать по файлу источнику
- Все операции отсортированы по дате
- Удобно для анализа всех операций вместе

### Режим 2: Разные листы (-s флаг)

Excel файл с несколькими листами:
- `8542637896` - операции из 1-го PDF
- `test_pdf_1` - операции из 2-го PDF
- `test_pdf_2` - операции из 3-го PDF
- `test_pdf_3` - операции из 4-го PDF

**Преимущества:**
- Ясная организация по источникам
- Легко найти конкретную выписку
- Удобно для архивирования

## 💡 Советы по использованию

### Массовая обработка

Если у вас много PDF файлов, поместите их все в одну папку:

```bash
mkdir my_statements
# Скопируйте все PDF в папку my_statements
python3 multi_pdf_to_excel.py -d my_statements -o combined.xlsx
```

### Автоматизация

Добавьте в cron для автоматической обработки:

```cron
# Каждый месяц объединять все PDF
0 1 1 * * cd /home/user/pdfs && python3 multi_pdf_to_excel.py -o monthly_$(date +\%Y\%m).xlsx
```

### Интеграция с другими программами

```python
import subprocess
import sys

# Запустить из Python скрипта
result = subprocess.run([
    sys.executable, 'multi_pdf_to_excel.py',
    '-d', './pdfs',
    '-o', 'combined.xlsx'
])

if result.returncode == 0:
    print("✅ Excel файл создан успешно")
else:
    print("❌ Ошибка при создании файла")
```

## 🔍 Поддерживаемые форматы PDF

- ✅ Выписки Сбербанка (все версии)
- ✅ T-Bank (все версии)
- ✅ Другие банки (если они используют похожий формат)

## ⚠️ Известные ограничения

1. **Большие файлы**: Если Excel файл содержит более 1 млн строк, некоторые версии Excel могут работать медленно
2. **Очень большие папки**: Если PDF файлов более 100, рекомендуется разбить на группы
3. **Память**: Для очень больших наборов рекомендуется использовать режим с отдельными листами (-s)

## 🐛 Решение проблем

### Ошибка: "PDF файлы не найдены"

**Решение:**
- Убедитесь что PDF файлы находятся в текущей папке
- Используйте абсолютный путь: `python3 multi_pdf_to_excel.py -d /полный/путь`
- Проверьте расширение файлов (должно быть `.pdf` в нижнем регистре)

### Ошибка: "Не удалось обработать ни один PDF"

**Решение:**
- Убедитесь что PDF файлы являются выписками Сбербанка/T-Bank
- Проверьте что PDF содержит текст (не отсканированное изображение)
- Попробуйте обработать один PDF отдельно: `python3 multi_pdf_to_excel.py file.pdf -o test.xlsx`

### Excel файл не открывается

**Решение:**
- Закройте файл если он уже открыт в Excel
- Попробуйте переименовать выходной файл: `-o output_new.xlsx`
- Проверьте место на диске
